===== MBTI测试应用 - 最终运行指南 =====

1. 启动服务器（选择其一）：
  方案A（推荐）- Python简易服务器：
    cd D:\chatgpt\mbti-test
    python -m http.server 8091 --bind 127.0.0.1
  方案B - Node.js服务器（换端口避免冲突）：
    set PORT=8092
    node server.js

2. 电脑浏览器访问：
    http://127.0.0.1:8091/ （或 8092）

3. 手机/QQ/微信访问：
    - 确保手机和电脑在同一Wi-Fi下
    - 查看终端输出的 PHONE_LAN 地址
    - 复制链接到微信/QQ聊天窗口发送或直接点开
    - 会在微信/QQ内置浏览器中直接打开答题页面

4. 离线使用（无需网络）：
    双击打开 index.html 即可（投稿功能需服务器支持）

5. 首次使用注意：
    - 加载5万题库可能需要2-5秒，请稍候
    - 题库加载完成后「开始快问快答」按钮自动激活
    - 可先填写昵称（如「已读不回仙人」「DDL魔法师」）
    - 选择分类（恋爱/学习/职场/搞笑等）或选「随机混合」

6. 功能特性速览：
    ✓ 5万+搞笑人格题库（4个口语化选项 + 哲理金句）
    ✓ 20个分类可选（恋爱/学习/职场/人生/搞笑/动漫/游戏...）
    ✓ 每题切换有翻动动画音效
    ✓ 结果含认真分析+人间锐评+职业建议+恋爱匹配
    ✓ 49+动物图鉴卡片（机械狼/夜猫子/沙皮狗等）
    ✓ 生成1:1 / 9:16海报下载
    ✓ 答题后可投稿新题去重入库
    ✓ 中英双语一键切换
    ✓ 手机/微信/QQ无缝访问
